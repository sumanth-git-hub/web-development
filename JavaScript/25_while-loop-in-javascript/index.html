While Loop in JavaScript | Types of Loops in JavaScript

Types of Loops in JavaScript are

  • While Loop
  • For Loop
  • Do-While Loop

What is Loop in JavaScript?

Loops in JavaScript are used to execute a block of code repeatedly until a specific condition is met.

What is while loop in JavaScript?

A "While" Loop is used to repeat a specific block of code an unknown number of times, until a condition is met.
