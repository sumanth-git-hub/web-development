How to Access Parent Sibling & Children Elements using JavaScript

Here is the list of Javascript Elements are used to find the Parent, children and Sibling

  • parentElement
    • - to find the Parent Element
  • parentNode
    • - to find the text content of the current element
  • children
    • - to find the children Element
  • childNode
    • - to find the text content of the current element
  • nextElementSibling
    • - to find the element of next sibling
  • nextSibling
    • - to find the text content next to current element
  • previousElementSibling
    • - to find the element of previous sibling element
  • previousSibling
    • - to find the previous text content to the current element
