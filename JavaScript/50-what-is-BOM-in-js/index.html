BOM in JavaScript [Browser Object Model]

The Browser Object Model (BOM) is a collection of objects exposed by the browser that allow JavaScript to interact with the browser window, document, and other browser-specific functionalities. The BOM includes objects such as Window, Navigator, Location, History, and Screen. The Window object serves as the entry point to the BOM and provides access to the other objects within it.
