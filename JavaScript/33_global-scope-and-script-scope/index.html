Global Scope and Script Scope in JavaScript

What is Global Scope?

The Javascript global scope is the context where everything in a Javascript program executes by default.

What is Script Scope?

In JavaScript, script scope is a type of scope that is created when a script is loaded. Variables declared in script scope are accessible from anywhere within the script, but not from outside the script.

What is Local Scope?

in local scope the variable can be accessed within a function where it is declared.
