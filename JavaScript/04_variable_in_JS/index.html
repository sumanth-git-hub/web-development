Variables in JavaScript

A JavaScript Variables is a name of storage location

and we can give that name in 3 ways

  • Using let Keyword
  • Using const Keyword
  • Using var Keyword

Rules for naming a variable

a variable name can contain any for the following charecter but must not start with a digit.

  • Capital letter: A to Z
  • Small letters: ato z
  • digits (0 to 9) but variable name should not begin with digit
  • Only 2 special charecter can be used wich is "$"" and "_"
